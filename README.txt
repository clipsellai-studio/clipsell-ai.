CLIPSELL AI — SITE BILINGUE FR / EN

Fichiers : index.html, style.css, script.js.

IMPORTANT : La vidéo de démonstration n'a pas pu être copiée automatiquement depuis Runway. Pour l'afficher dans le portfolio, téléchargez la vidéo MP4 depuis Runway, renommez-la exactement demo.mp4 et placez-la à côté de index.html.

HÉBERGEMENT GRATUIT SUR GITHUB PAGES :
1. Créez un compte GitHub si nécessaire.
2. Créez un dépôt public nommé clipsellai-site (ou autre nom disponible).
3. Importez index.html, style.css, script.js et demo.mp4 dans la racine du dépôt.
4. Dans Settings > Pages, choisissez Deploy from a branch, main, / (root), puis Save.
5. Votre site sera accessible à une adresse de type https://VOTRE-PSEUDO.github.io/clipsellai-site/ après publication.

Si vous préférez une URL https://VOTRE-PSEUDO.github.io/, le dépôt doit être nommé exactement VOTRE-PSEUDO.github.io.

Le site n'invente aucun client ni témoignage. Il utilise l'adresse clipsellai.contact@gmail.com. Il n'y a pas de collecte de données ni de formulaire serveur : le contact ouvre l'application mail du visiteur.
